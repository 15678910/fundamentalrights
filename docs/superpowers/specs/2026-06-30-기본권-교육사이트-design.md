# 우리 헌법 기본권 교육 사이트 — 설계서

작성일: 2026-06-30
참고 사이트: Grundrechte-Fibel(LpB BW), bpb "쉬운 정치", HanisauLand

---

## 1. 목적과 대상

대한민국 현행 헌법 **제2장(국민의 권리와 의무, 제10조~제39조)**의 기본권을
**초등학생부터 성인까지** 누구나 자기 수준에서 이해할 수 있도록 설명하는
정적 교육 웹사이트.

독일 Grundrechte-Fibel의 핵심 아이디어 — *하나의 헌법 텍스트를 여러 난이도로
번역해 같은 권리를 모든 연령이 이해하게 한다* — 를 한국 헌법에 적용한다.

## 2. 핵심 콘텐츠 모델

- 각 권리 = **하나의 Markdown 파일** (한 권리 = 한 파일, 유지보수·검수 용이).
- 한 파일 안에 **3단계 설명 + 헌법 원문 + 메타데이터 + 퀴즈**를 함께 담는다.
- 난이도 전환은 화면에서 보여주기/숨기기 (별도 페이지 분리 없음).

### 난이도 3단계

| 단계 | 대상 | 성격 |
|------|------|------|
| 쉬운 말 | 초등 | 짧은 문장, 일상어, 비유 |
| 보통 | 청소년 | 개념어 + 풀이, 생활 예시 |
| 자세히 | 성인 | 정확한 법적 표현, 판례·사례 |

여기에 **헌법 원문**을 항상 펼쳐볼 수 있게 별도 표시(난이도 단계와 별개).

### 파일 구조 예시

```
src/content/rights/
  10-인간의-존엄.md
  11-평등권.md
  ...
  39-국방의무.md
```

```yaml
---
조문번호: 10
제목: 인간의 존엄과 행복추구권
범주: 포괄적기본권
아이콘: dignity
원문: "모든 국민은 인간으로서의 존엄과 가치를 가지며, 행복을 추구할 권리를 가진다. ..."
관련용어: [기본권, 행복추구권]
퀴즈:
  - 질문: 인간의 존엄은 누구에게 있을까요?
    선택지: [모든 사람, 어른만]
    정답: 0
    해설: 인간의 존엄은 모든 사람에게 똑같이 있어요.
---
## 쉬운 말
(초등 수준 본문)
## 보통
(청소년 수준 본문)
## 자세히
(성인 수준 본문 — 판례·사례 포함)
```

## 3. 범위 — 제2장 전체

제10조~제39조를 6개 범주로 묶어 메뉴·색상에 사용:

1. **포괄적 기본권** — 제10조(인간의 존엄·행복추구)
2. **평등권** — 제11조
3. **자유권** — 제12~22조 (신체·거주이전·직업·주거·사생활·통신·양심·종교·표현·학문예술 등)
4. **참정권** — 제24~25조 (선거권·공무담임권)
5. **청구권** — 제26~30조 (청원·재판·국가배상·형사보상·범죄피해자구조)
6. **사회권** — 제31~36조 (교육·근로·노동3권·인간다운생활·환경·혼인가족·보건)
7. **국민의 의무** — 제38~39조 (납세·국방)

> 재산권(제23조)은 자유권 범주에, 기본권 제한의 일반원칙(제37조)은
> "기본권을 지키는 약속" 같은 별도 해설 항목으로 다룬다.

> 총 25~30개 항목. 일부 조문(예: 제12~13조의 신체의 자유·죄형법정주의)은
> 가독성을 위해 여러 항목으로 나누거나 묶을 수 있다(콘텐츠 작성 시 확정).

## 4. 사이트 맵

| 경로 | 내용 |
|------|------|
| `/` | 홈 — 소개, 난이도 안내, 범주별 권리 카드 그리드 |
| `/rights/[조문]` | 권리 상세 — 난이도 토글, 원문, 퀴즈, 관련 용어, 이전/다음 |
| `/glossary` | 용어 사전 (가나다순 + 본문 내 링크) |
| `/about` | 소개, 출처, 검수 안내, 면책 문구 |
| (전역) | 검색 (Pagefind) |

## 5. 디자인 시스템 (Grundrechte-Fibel 참조)

- **톤**: 미니멀, 흰 배경(#ffffff), 진한 본문 글자(#1e293b), 파란 포인트(#2563eb).
- **타이포그래피**: 한글 산세리프(Pretendard 또는 system-ui), 본문 line-height 1.7.
- **마스코트**: 각 권리를 안내하는 친근한 캐릭터(초기엔 이모지/플레이스홀더 →
  추후 일러스트 교체). 범주별 색상 구분.
- **레이아웃**: 단일 컬럼(A안). 모바일 우선, 데스크톱에서 중앙 정렬 본문 폭 제한.
- **컴포넌트**: 난이도 토글, 접근성 버튼(고대비·글자 크게), 원문 펼침(accordion),
  퀴즈 카드, 권리 카드, 용어 툴팁/링크, 검색창.

## 6. 기능 (MVP 포함)

- **난이도 토글** — 쉬운 말/보통/자세히 전환(소형 JS, localStorage로 선택 기억).
- **용어 사전** — 본문 속 용어 클릭 시 쉬운 설명(툴팁 또는 사전 페이지 링크).
- **퀴즈** — 권리별 객관식/OX, 즉시 정답·해설 표시(클라이언트 측).
- **검색** — Pagefind 정적 검색(빌드 시 인덱스 생성, 서버 불필요).
- **삽화/아이콘** — 범주·권리별 아이콘. 초기엔 자리표시 후 교체.
- **접근성** — 고대비 모드, 글자 크기 확대, 시맨틱 HTML, 키보드 내비게이션,
  WCAG AA 대비 목표.
- **인쇄/PDF** — 브라우저 인쇄에 최적화된 print 스타일.

## 7. 기술 스택

- **Astro** 정적 사이트 + **Content Collections**(Markdown + 스키마 검증).
- 최소한의 클라이언트 JS(난이도 토글·퀴즈·접근성).
- **Pagefind** 정적 검색.
- 폰트: Pretendard(웹폰트) 또는 system-ui 폴백.
- 빌드 산출물은 순수 정적 파일 → **GitHub Pages**(또는 Netlify/Vercel) 무료 배포.

## 8. 콘텐츠 정확성 (중요)

- 3단계 설명 초안은 **헌법 원문 + 공개 권위 자료**(헌법재판소 판례,
  국가인권위 자료, 표준 헌법 교재)를 근거로 작성한다.
- 각 권리 페이지/소개 페이지에 **출처와 면책 문구**를 명시:
  "본 설명은 학습용 요약이며 법적 효력이 있는 해석이 아닙니다. 정확한 내용은
  헌법 원문과 공식 자료를 확인하세요."
- **배포 전 전문가/교사 감수**를 권장(README와 about에 명시).

## 9. 비범위 (YAGNI — 1차 제외)

- 로그인·회원·진도 저장(서버), 댓글, 다국어, 수어 영상, 음성 낭독, CMS.
- 위 항목은 정적 구조를 깨지 않으므로 추후 확장 가능(특히 음성·수어는
  Grundrechte-Fibel 후속 단계로 검토).

## 10. 검증 기준

- `astro build` 성공 + Content Collection 스키마 검증 통과(모든 권리 파일 필수 필드 충족).
- 권리 상세 페이지에서 3단계 토글·원문 펼침·퀴즈가 실제 동작(미리보기 확인).
- Pagefind 검색이 빌드 후 권리·용어를 찾음.
- 모바일/데스크톱 반응형, 고대비·글자 확대 동작.
- 키보드만으로 주요 흐름 이용 가능, 색 대비 WCAG AA 충족.
