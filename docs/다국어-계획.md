# 이주민을 위한 다국어 계획

작성: 2026-09-13. 세 단계 가운데 1단계 완료, 2단계 일부 진행, 3단계는 언어 선정 후 착수.

## 원칙

- **전 페이지를 사이트가 직접 번역해 싣지 않는다.** 검증 불가능한 법률 용어 오역이 우리 이름으로 게시되면 "검증된 사실만, 미확인은 명시" 원칙과 충돌한다. 독일 bpb·lpb도 핵심 자료만 몇 개 언어로 제공한다.
- 전 페이지 번역은 **브라우저 내장 번역**에 맡기고, 우리는 (1) 그 사용법 안내, (2) 이주민에게 직접 필요한 핵심 자료의 **사람이 검수한 번역**에 집중한다.
- 번역문은 검수 전까지 "검수 전 초안"임을 표시하고, 모어 화자의 교정을 GitHub·이메일로 받는다.
- 새 일러스트에는 글자를 넣지 않는다(이미지 속 글자는 어떤 방식으로도 번역되지 않음).

## 1단계 — 완료 (2026-09-13)

- `/language` — 15개 언어 브라우저 번역 안내(Android Chrome · iPhone Safari · PC), 기계번역 주의, 다국어 상담 1345
  - 영어·베트남어·중국어·네팔어·인도네시아어·크메르어·태국어·우즈베크어·몽골어·미얀마어·필리핀어·벵골어·싱할라어·우르두어·러시아어 + 쉬운 한국어 안내
- 헤더 🌐 Languages 버튼(좁은 화면은 아이콘만), 푸터 링크, 홈 둘러보기 타일
- 검증한 사실: 법무부 외국인종합안내센터 1345 — 20개 언어, 평일 09:00~22:00(18시 이후 한·중·영), 통화료 부과(무료 아님), 2026-05-27 인권침해 신고 전용 '1번' 신설(법무부 보도자료 2026-07-06)
- 확인된 제약: Google 웹사이트 번역 프록시(translate.goog)는 국내에서 "이 지역에서는 사용할 수 없음"으로 차단됨 → 링크 한 번으로 번역된 사이트를 여는 방식은 불가. 브라우저 내장 번역만 안내.

## 2단계 — 주제 특집 13 「이주 노동자와 기본권」 (한국어)

헌법 제6조 ②, 헌재의 '인간의 권리 / 국민의 권리' 구분, 체류자격과 무관하게 적용되는 노동법, 사업장 변경 제한의 찬반, 도움받을 곳. 이주민이 브라우저 번역으로 읽어도 되도록 쉬운 문장으로.

## 3단계 — 핵심 자료의 검수 번역 (언어 선정 후)

### 대상 자료(분량 순)

1. 용어사전 24개 — 각 1~3문장, 가장 작음
2. 특집 13 「이주 노동자와 기본권」 — 1편
3. 조항 30편의 **'쉬운 말' 단계만** — 조항당 5~8문장
4. (선택) 상담 창구 카드 한 장 — 1345·1350·1331·112·119

영어는 한국법제연구원(KLRI) 헌법 영역본(elaw.klri.re.kr / law.go.kr 영문법령)을 조문 대조 자료로 쓴다. 이용 조건 확인 필요.

### 언어 선정안

법무부 출입국·외국인정책 통계월보 2026년 6월호(특집 13 집필 시 검증): 체류 외국인 2,874,278명, 등록 외국인 1,636,922명, 국적 순위 중국·베트남·미국·태국·우즈베키스탄, 네팔 첫 10만 명 돌파. 고용허가제(E-9) 체류 약 28만 7천 명(2026.7, 고용노동부 자료 인용 보도). 등록 외국인 기준 상위(2025.12, 2차 인용): 중국 47.8만(한국계 포함) · 베트남 29.4만 · 네팔 8.9만 · 우즈베키스탄 6.9만 · 캄보디아 6.5만 · 인도네시아 6.2만.
고용허가제(E-9) 송출국은 17개국(베트남·필리핀·태국·인도네시아·몽골·스리랑카·캄보디아·우즈베키스탄·파키스탄·미얀마·네팔·방글라데시·키르기스스탄·동티모르·라오스·중국·타지키스탄).

| 우선순위 | 언어 | 근거 |
|---|---|---|
| 1차(5개) | 베트남어 · 중국어(간체) · 네팔어 · 크메르어 · 인도네시아어 | 체류 규모 상위 + E-9 비중 |
| 1차 공통 | 영어 | 필리핀·스리랑카·남아시아 출신의 공통어, KLRI 대조본 존재 |

| 3차 | 필리핀어 · 벵골어 · 싱할라어 · 우르두어 · 러시아어 | 1345 지원 언어와 맞춤 |

### 구현 방식(안)

- 콘텐츠 컬렉션에 `translations/{lang}/…` 폴더 또는 조항 frontmatter에 `easy_{lang}` 필드. 조항 페이지 상단에 언어 칩(있는 언어만 표시).
- 번역문 옆에 항상 한국어 원문 병기 + "검수 전 초안 / Draft, not yet reviewed" 표시.
- 감수자 섭외 시 "베트남어·중국어·네팔어 검수자"를 함께 구한다(이주민 지원단체·다문화가족지원센터·대학 유학생회).

## 미확인·남은 검토 사항

- 통계월보 원문 수치 재확인(위 표는 2차 인용)
- KLRI 영역본 이용 조건
- Samsung Internet 자체 번역 메뉴의 정확한 위치(안내문은 Chrome 기준으로 작성)
- 15개 언어 안내문 모어 화자 검수(현재 자체 번역 초안)
