## 활동 안내

헌법 제34조는 말합니다 — 모든 국민은 인간다운 생활을 할 권리를 가진다고요.
그래서 우리는 모두가 조금씩 미리 내어 곳간을 채우고, 큰일을 당한 사람을 그 곳간으로 돕습니다.
오늘은 그림을 관찰하고, 놀이를 기록하며, 이 곳간의 비밀을 찾아봅시다.

**소요 시간:** 약 25~35분
**준비물:** 연필, 이 워크시트

---

## 활동 1. 그림을 관찰해요

선생님이 보여 주신 그림을 말없이 잘 들여다보세요. 그리고 적어 봅시다.

**그림에서 보이는 것 3가지**

```
1. _______________________________________________________

2. _______________________________________________________

3. _______________________________________________________
```

**그림을 보고 궁금한 것 1가지**

```
_________________________________________________________?
```

**가운데에 있는 곳간, 정체가 뭘까요? 내 추측을 적어 보세요.**

```
_________________________________________________________
```

---

## 활동 2. 어떤 곳간이 도와줄까요? — 짝짓기

이런 일이 생기면 어느 곳간이 도와줄까요? 알맞은 것끼리 선으로 이어 보세요.

| 이런 일이 생겼어요 | | 이 곳간이 도와줘요 |
|---|---|---|
| 아플 때 · | | · 국민연금 |
| 나이 들었을 때 · | | · 산재보험 |
| 일자리를 잃었을 때 · | | · 건강보험 |
| 일하다 다쳤을 때 · | | · 고용보험 |

이 네 가지 곳간을 **4대 사회보험**이라고 합니다.

---

## 활동 3. 공동 곳간 놀이 기록표

우리 반 공동 곳간 놀이를 하면서 기록해 보세요.

| | 1판 | 2판 | 3판 |
|---|---|---|---|
| 곳간에 낸 쿠폰 | 장 | 장 | 장 |
| 내가 뽑은 카드 | | | |
| 곳간에서 받은 쿠폰 | 장 | 장 | 장 |

**놀이를 하고 느낀 점**

```
아무 일 없던 판, 내 마음은 어땠나요?
_________________________________________________________

큰일 카드를 뽑은 친구를 보며 어떤 생각이 들었나요?
_________________________________________________________

곳간이 없었다면 어떻게 되었을까요?
_________________________________________________________
```

---

## 활동 4. 연대란 무엇일까요

오늘 수업을 지나온 나만의 문장을 완성해 보세요. 정답은 없습니다.

```
연대란 ___________________________________________ 이다.
```

나라의 큰 곳간 말고, **우리 반에서 내가 실천할 수 있는 작은 연대**를 한 가지 적어 보세요.
(예: 준비물을 깜빡한 친구와 같이 쓰기, 아픈 친구에게 알림장 전해 주기)

```
이번 주에 내가 해 볼 작은 연대:

_________________________________________________________
```

## 교사용 안내

> **참고:** 이 워크시트는 수업 [함께 채우는 곳간 — 공동체와 연대](../../lessons/11-공동체와-연대-공동-곳간)의 1·2·3·5단계 활동을 학습지 형태로 옮긴 것입니다. 수업과 함께 쓰거나, 단독 활동지로도 사용할 수 있습니다.

- 활동 1은 '말 없는 그림' 도입과 함께 사용하세요. 교사가 그림을 설명하기 전에 학생이 먼저 관찰하고 추측하는 것이 핵심입니다.
- 활동 3의 놀이 카드는 전부 가상 상황으로만 구성하고, 특정 학생의 실제 가정 형편이 화제가 되지 않도록 해 주세요. 보험료율 등 실제 수치는 다루지 않습니다.
- 활동 2 정답: 아플 때↔건강보험, 나이 들었을 때↔국민연금, 일자리 잃었을 때↔고용보험, 일하다 다쳤을 때↔산재보험.
