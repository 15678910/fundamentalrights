## 활동 안내

**소요 시간:** 약 25~35분

## 활동 1. 모의 근로계약서 작성하기

가상의 아르바이트를 하나 정해 아래 계약서의 빈칸을 채워 보세요. (예: 분식집 주말 홀서빙, 편의점 평일 저녁 근무)

다 쓴 뒤, **법적으로 반드시 계약서에 들어가야 한다고 생각하는 항목**의 번호 옆 괄호에 ★를 표시하세요.

> **근로계약서 (모의 작성용)**
>
> 사업주(사장님) 이름: ______________  /  근로자(나) 이름: ______________

| 번호 | 항목 | 내용 쓰기 | ★ 표시 |
|------|------|-----------|--------|
| 1 | 근무 장소 | | ( ) |
| 2 | 하는 일(업무 내용) | | ( ) |
| 3 | 근로시간 (몇 시부터 몇 시까지, 주 며칠) | | ( ) |
| 4 | 휴게시간 (언제, 몇 분) | | ( ) |
| 5 | 시급 | 시급 __________ 원 | ( ) |
| 6 | 임금 지급일 | 매월 ______ 일 | ( ) |
| 7 | 임금 지급 방법 (계좌이체/현금 등) | | ( ) |
| 8 | 주휴수당 (받는 조건과 금액) | | ( ) |

```
사업주 서명: ______________          근로자 서명: ______________

작성한 날짜: 20____년 ____월 ____일
```

**점검 질문 1.** 내가 쓴 시급은 최저임금 이상인가요? 수업에서 배운 2026년 기준 최저임금은 시급 10,320원입니다. (최저임금은 해마다 바뀌니, 실제로 일을 시작하기 전에 그해 금액을 꼭 확인하세요.)

```
나의 시급 __________ 원  →  최저임금 이상이다 ( O / X )
```

**점검 질문 2.** 계약서는 몇 부를 만들어서 누가 가져야 할까요?

```
______ 부를 만들어, ______________________ 가 각각 가진다.
```

## 활동 2. 이 상황, 괜찮을까? — 시나리오 판단표

수업에서 만난 네 가지 상황입니다. 각각 '괜찮다' 또는 '문제다'에 O를 치고, 그렇게 판단한 근거(헌법·법의 기준)를 써 보세요.

**시나리오 1.** 편의점에서 한 달을 일했는데 사장님이 "다음 달에 줄게"라며 월급을 미룹니다.

```
판단: 괜찮다 / 문제다

근거가 되는 조항·기준:
_____________________________________________________
```

```
판단: 괜찮다 / 문제다

근거가 되는 조항·기준:
_____________________________________________________
```

**시나리오 3.** "계약서는 나중에 쓰자"며 일부터 시작하자고 합니다.

```
판단: 괜찮다 / 문제다

_____________________________________________________
```

## 교사용 안내

> **참고:** 학생 답안은 표현이 달라도 핵심 개념이 맞으면 인정하고, 근거를 조항·기준과 연결하도록 지도하세요.

**활동 1** — 표의 여덟 항목은 모두 근로계약서에 들어가야 할 핵심 항목입니다. ★ 표시 활동의 목적은 정답 고르기가 아니라 "무엇이 빠지면 위험한지" 토론을 여는 데 있습니다. 특히 근로시간·휴게·임금(구성 항목·계산 방법·지급 방법)은 서면 명시 사항임을 짚어 주세요. 점검 질문 2의 답: 2부를 만들어 사업주와 근로자가 각각 1부씩 가진다(근로자에게 반드시 교부).

**활동 2 예시 답안**

- 시나리오 1: **문제다.** 일한 대가는 정해진 지급일에 받아야 하며, 밀린 월급은 고용노동청에 진정을 넣어 받아낼 수 있다. 헌법 제32조가 보장하는 근로의 권리와 근로기준법의 임금 지급 원칙에 어긋난다.
- 시나리오 2: **문제다.** 주휴수당은 조건을 채우면 받아야 하는 수당이지, 사장님이 주면 고마운 것이 아니다.
- 시나리오 3: **문제다.** 근로계약서는 반드시 써서 한 부를 근로자에게 주어야 한다. 약속이 종이에 없으면 나중에 말이 달라져도 증명하기 어렵다.
- 시나리오 4: **문제다.** 18세 미만은 밤 10시부터 새벽 6시까지 원칙적으로 일을 시킬 수 없고(본인 동의와 고용노동부 인가가 있어야만 예외), 하루 7시간·1주 35시간 한도도 넘기 쉽다. 헌법 제32조의 "연소자의 근로는 특별한 보호를 받는다"가 근거.

**활동 3** — 증거 예시: 근로계약서, 근무 기록, 대화 캡처. 실제 아르바이트 중이거나 임금 체불을 겪고 있는 학생이 있을 수 있으니, 발표를 강요하지 말고 수업 후 개별 상담 창구(1644-3119)를 조용히 안내해 주세요.

**수치 안내** — 최저임금(2026년 기준 시급 10,320원)과 근로기준법 수치는 개정될 수 있으니, 수업 전 최저임금위원회·고용노동부 자료로 그해 기준을 확인하고 진행하세요.
