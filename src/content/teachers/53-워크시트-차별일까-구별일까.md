## 활동 안내

똑같이 '들어갈 수 없는 자리'인데, 어떤 것은 괜찮아 보이고 어떤 것은 아니라고 느껴집니다.
아래 카드 다섯 장을 직접 나누어 보고, 나만의 기준을 세워 봅시다. 정답은 없습니다 — 중요한 것은 **나의 이유**입니다.

**소요 시간:** 약 20~30분
**준비물:** 연필, 이 워크시트

---

## 활동 1. 카드 분류하기

다음 다섯 장의 카드를 읽고, 아래 표에 나누어 넣어 보세요.

> **카드 1.** 어린이 출입을 금지한 '노키즈존' 식당
> **카드 2.** 여성전용 주차구역
> **카드 3.** 지하철의 노약자석
> **카드 4.** 장애인 전용 주차구역
> **카드 5.** 밤 10시 이후 청소년 출입을 금지한 PC방

| 카드 번호 | 차별이다 | 괜찮은 구별이다 | 그렇게 나눈 나의 기준 (한 문장) |
|---|---|---|---|
| 1 | ☐ | ☐ | |
| 2 | ☐ | ☐ | |
| 3 | ☐ | ☐ | |
| 4 | ☐ | ☐ | |
| 5 | ☐ | ☐ | |

**짝과 비교해 봅시다.** 짝과 다르게 분류한 카드는 몇 번인가요?

```
다르게 나눈 카드: ______ 번
짝의 기준은 나와 어떻게 달랐나요?
_____________________________________________________
```

## 활동 2. '합리적 이유' 3질문으로 다시 보기

평등은 '모두를 무조건 똑같이 대하기'가 아닙니다. **같은 것은 같게, 다른 것은 다르게** — 그래서 질문은 "다르게 대할 **합리적인 이유**가 있는가?"입니다.

활동 1에서 가장 판단하기 어려웠던 카드 한 장을 골라, 세 가지 질문을 던져 보세요.

**내가 고른 카드:** ______ 번

```
질문 1. 누구를, 왜 다르게 대하고 있나요?
_____________________________________________________

질문 2. 그 이유는 그 집단 전체에 해당하나요,
        아니면 일부의 사례를 전체로 일반화한 것인가요?
_____________________________________________________

질문 3. 다르게 대하지 않으면(제한을 없애면) 누가, 얼마나 불편해지나요?
_____________________________________________________
```

**3질문을 거친 뒤, 이 카드에 대한 나의 판단은?**

```
☐ 처음과 같다   ☐ 바뀌었다
이유: ________________________________________________
```

> **참고:** 국가인권위원회는 2017년, 13세 이하 아동의 출입을 일률적으로 금지한 식당에 대해 합리적 이유가 없는 차별이라고 판단하고 배제하지 말 것을 권고했습니다. 일부 아동이 소란을 피운 사례가 있더라도, 그것을 이유로 모든 아동과 그 가족을 막는 것은 일부를 전체로 일반화한 것이라고 보았습니다.

## 활동 3. 우리 학교 접근성 점검표

이번에는 우리가 매일 지내는 학교를 점검합니다. **누군가에게만 유난히 불편한** 공간이나 규칙을 두 가지 찾아 적어 보세요.
(예: 목발을 짚은 친구에게 계단은? 키가 작은 저학년에게 정수기 높이는? 한글이 서툰 친구에게 안내문은?)

**점검 1**

| 항목 | 내용 |
|---|---|
| ① 어떤 공간/규칙인가요? | |
| ② 누구에게 불편한가요? | |
| ③ 어쩔 수 없는 것인가요, 고칠 수 있는 것인가요? | ☐ 어쩔 수 없다  ☐ 고칠 수 있다 |
| ④ 내가 제안하는 개선안 한 가지 | |

**점검 2**

| 항목 | 내용 |
|---|---|
| ① 어떤 공간/규칙인가요? | |

## 교사용 안내

> **참고:** 이 워크시트는 수업 [모두의 자리 — 차별일까 구별일까](../../lessons/07-모두의-자리-차별과-평등)의 1·2·4·5단계 활동을 학습지 형태로 옮긴 것입니다. 수업과 함께 쓰거나, 단독 활동지로도 사용할 수 있습니다.

- 활동 1에서 교사가 '정답'을 정해 주지 마세요. 여성전용 주차구역, 청소년 심야 출입 제한처럼 사회적으로도 평가가 갈리는 항목은 갈린 채로 두고, 활동 2의 '합리적 이유' 3질문을 학생 스스로 적용해 보게 하는 것이 목적입니다.
- 활동 3에서 특정 학생(장애·체격·가정 배경 등)이 사례로 지목되지 않도록, 반드시 '가상의 사용자' 관점으로 진행하세요.
- 활동 3의 개선안 중 실현 가능한 것은 학생자치회 건의함과 연결하면 효과가 큽니다.
