## 활동 2. 판별 과제 — 보호되는 말일까?

다섯 개의 사례를 읽고 O, X, △ 중 하나에 동그라미 하세요.

- **O** = 표현의 자유로 보호되는 말
- **X** = 보호되지 않는 말
- **△** = 생각이 나뉘는 말

| 사례 | 나의 판단 |
|---|---|
| 1. "급식이 맛없어요. 바꿔 주세요"라고 건의함에 쓰기 | O / X / △ |
| 2. "선생님의 그 결정은 잘못됐다고 생각해요"라고 의견 말하기 | O / X / △ |
| 3. 친구 외모를 놀리는 별명을 지어 퍼뜨리기 | O / X / △ |
| 4. 사실이 아닌 소문을 지어내서 퍼뜨리기 | O / X / △ |
| 5. "우리 반 규칙이 불공평해요"라고 항의하기 | O / X / △ |

## 교사용 안내

> **참고:** 이 워크시트는 수업 [기본권 여행 — 네 가지 이야기](../../lessons/12-기본권-여행-네-가지-이야기)의 2·4·6단계 활동을 학습지 형태로 옮긴 것입니다. 수업과 함께 쓰거나, 단독 활동지로도 사용할 수 있습니다.

- 활동 1의 답 예시: ① 제21조(표현의 자유) ② 제20조(종교의 자유)·제19조(양심의 자유) ③ 제11조(평등권) ④ 제12조(신체의 자유). 조문 번호보다 '어떤 권리인지'를 자기 말로 설명하는 것을 더 중요하게 봐 주세요.
- 활동 2에서 △로 의견이 갈리는 사례는 정답을 정해 주지 않고 갈린 채로 두어도 좋습니다(보이텔스바흐 원칙). 기준 문장은 "생각·의견은 넓게 보호되지만, 사람을 겨눈 공격과 지어낸 거짓은 아니다"라는 방향이 드러나면 폭넓게 인정합니다.
- **활동 3(가족 인터뷰)은 가정 상황이 드러나는 활동입니다.** 반드시 선택 과제로 안내하고, 결과 발표를 강요하지 마세요. 다양한 가족 형태를 전제로 "집의 어른 누구든"이라고 안내하고, 가정 형편이 비교되는 발문은 피합니다.
