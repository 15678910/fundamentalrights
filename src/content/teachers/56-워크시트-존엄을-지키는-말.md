## 활동 안내

헌법 제10조는 말합니다 — 모든 사람은 인간으로서 존엄과 가치를 가진다고요.
존엄은 잘해서 받는 상이 아니라, **사람이라서** 처음부터 갖고 태어나는 것입니다.
오늘은 존엄이 다치는 순간을 들여다보고, 그것을 지키는 말을 연습해 봅시다.

**소요 시간:** 약 30~40분
**준비물:** 연필, 이 워크시트

---

## 활동 1. 그때 그 친구 마음은?

네 장의 상황 카드를 읽어 보세요. 카드 속 친구들은 모두 가상의 친구입니다.

> **카드 1.** 하람이는 이름 대신 놀리는 별명으로만 불립니다. 하지 말라고 해도 "장난인데 왜 그래?"라는 말이 돌아옵니다.
> **카드 2.** 쉬는 시간마다 하는 단체 놀이에서 두리만 늘 빠집니다. 아무도 이유를 말해 주지 않습니다.
> **카드 3.** 소은이가 한 사람에게만 말한 비밀이 며칠 만에 반 전체에 퍼졌습니다.
> **카드 4.** 몇몇 아이들이 재하에게 자기들 가방을 들게 하고, 싫다고 하면 "그럼 너랑 안 놀아"라고 합니다.

카드마다 두 가지를 적어 보세요.

| 카드 | 그 친구의 마음은? (마음 낱말로) | 힘은 어느 쪽이 컸나요? (여럿과 하나, 큰 쪽과 작은 쪽…) |
|---|---|---|
| 1. 하람 | | |
| 2. 두리 | | |
| 3. 소은 | | |
| 4. 재하 | | |

**생각해 봅시다.** 당하는 친구가 아무 말도 하지 않았다면, 그건 괜찮다는 뜻일까요?

```
☐ 그렇다   ☐ 아니다
왜 그렇게 생각하나요? _______________________________________
```

## 활동 2. 존엄 온도계

말에는 온도가 있습니다. 들으면 마음이 따뜻해지는 말이 있고, 마음이 얼어붙는 말이 있지요.
아래 여섯 개의 말을 읽고, 따뜻한 말인지 차가운 말인지 나누어 보세요.

> ㄱ. "너 그것도 못 해?"
> ㄴ. "괜찮아, 같이 다시 해 보자."
> ㄷ. "쟤랑 놀지 마."
> ㄹ. "네 생각을 더 듣고 싶어."
> ㅁ. "장난인데 왜 그래?"
> ㅂ. "그만해, 그건 장난이 아니야."

| 따뜻한 말 (기호) | 차가운 말 (기호) |
|---|---|
| | |

이번에는 **차가운 말 중 두 개**를 골라, 같은 상황에서 할 수 있는 따뜻한 말로 바꿔 써 보세요.

```
고른 말: ______ → 바꾼 말: _____________________________________

고른 말: ______ → 바꾼 말: _____________________________________
```

## 활동 3. 역할극 대본 틀 — 결말을 바꾸는 사람들

모둠에서 카드 한 장을 골라 짧은 역할극을 만듭니다. 카드 속 가상의 이름만 사용하세요.

**우리 모둠이 고른 카드:** ______ 번

**1막 — 존엄이 다치는 장면 (30초)**

```
어떤 말과 행동이 나오나요?
_____________________________________________________
_____________________________________________________
```

**2막 — 결말 바꾸기.** 누군가 한 사람이 다르게 행동해서 결말을 바꿉니다. 방법을 하나 고르세요.

```
☐ 멈추게 하는 한마디   ☐ 곁에 서 주는 행동   ☐ 어른에게 알리기
```

```
장면을 바꾸는 한마디(또는 행동):
_____________________________________________________

바뀐 결말은 어떻게 되나요?
_____________________________________________________
_____________________________________________________
```

## 활동 4. 우리 반 존엄 약속

우리 모둠이 제안하는 '서로의 존엄을 지키는 원칙'을 써 보세요. 벌칙이 아니라 **지키고 싶은 약속**의 말로 씁니다.

```
제안 1. __________________________________________________

제안 2. __________________________________________________
```

반에서 토의와 투표로 채택된 우리 반 존엄 약속을 적고, 서명해 봅시다.

```
우리 반 존엄 약속

1. _______________________________________________________

2. _______________________________________________________

3. _______________________________________________________

나는 이 약속을 지키겠습니다.     서명: ______________
```
